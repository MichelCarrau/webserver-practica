# Webserver Práctica

Servidor web desarrollado con Node.js que muestra una página de promoción de productos de belleza de las marcas **Bissu**, **Saniye** y **Prosa**.

## Tecnologías utilizadas

- Node.js
- Microsoft Azure (Máquina Virtual)
- Ubuntu Server 22.04 LTS
- HTML y CSS

## Cómo ejecutar

```bash
node index.js
